## Проект SOAR: Автоматизация реагирования
Самым сложным и интересным этапом стала разработка системы SOAR. Мы не просто настроили сбор логов, а создали полноценный «иммунитет» для лаборатории.

**Что было сделано:**
*   Развернут локальный Shuffle (Docker Compose) для обхода лимитов облачной версии.
*   Настроена интеграция Wazuh ➔ Shuffle через кастомный Bash-скрипт.
*   Написан Python-скрипт для работы с Wazuh API (получение JWT-токена, отправка Active Response).
*   Решена проблема с передачей IP-адреса в скрипт `firewall-drop` (через формирование объекта `alert`).

**Результат:** При атаке SSH-брутфорса система автоматически блокирует IP атакующего в `iptables` и присылает уведомление на почту. Это сокращает время реагирования (MTTR) с часов до секунд.
