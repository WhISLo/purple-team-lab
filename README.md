# purple-team-lab

По факту это не будет с 0 написаным проектом. Скорее всего я просто займусь пересборкой уже выполненых проектов, снова пройдусь по тем пунктам что не документировал и не скриншотил.
мне кажется это будет полезным опытом оформления докментации и визуализацией уже проделаной работы.
Сейчас у меня в лаборатории 4 машины.
Kali 10.10.10.203
Ubuntu 10.10.10.20
Windows Server 2016 10.10.10.200
Windows 10 10.10.10.201

На ubuntu установлен Wazuh как SIEM и Mythic для проведения атак. На WinSer и Win10 установлен Wazuh клиент для отлежживания подозрительной активности, они подключены к журналам windows defender.
По этому алерты срабатывают не всегда, но это удобно для меня в плане изучения того как добавлять новые правила и как отследить что они выполняются.
Дополнительно на Kali и ubuntu развернут Doker именно на основе него в ubuntu запущен wazuh, а в kali запускался juice shop для отработки навыков.
