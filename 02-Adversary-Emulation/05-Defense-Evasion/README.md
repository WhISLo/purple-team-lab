# Обход защиты (Defense Evasion)

## Обход Windows Defender

При запуске C2-агента `apollo.exe` Windows Defender блокировал файл. Для обхода были выполнены следующие действия:
1. Отключена «Защита в реальном времени» (временно).
2. Добавлена папка `C:\Users\Public\` в исключения.
3. После запуска защита была возвращена в исходное состояние.

**MITRE ATT&CK:** T1562.001.
