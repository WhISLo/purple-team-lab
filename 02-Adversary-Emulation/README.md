# Red Team: Эмуляция действий противника

В этом разделе описаны выполненные атаки с привязкой к тактикам MITRE ATT&CK.

## Выполненные техники
- **Initial Access:** Эксплуатация веб-уязвимостей (OWASP Juice Shop).
- **Execution:** Запуск C2-агента (Apollo) через Mythic.
- **Persistence:** Закрепление через планировщик задач Windows.
- **Credential Access:** Kerberoasting, AS-REP Roasting, DCSync.
- **Defense Evasion:** Обход Windows Defender.
