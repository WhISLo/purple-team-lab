# Инцидент 003: Обнаружение и автоматическая блокировка SSH-брутфорса

**Дата:** 2026-11-03
**Атакующий:** Kali Linux (10.10.10.203)
**Цель:** Ubuntu (10.10.10.20, агент 004)
**Инструмент атаки:** SSH (неудачные попытки входа)

## Executive Summary
С машины Kali был запущен брутфорс SSH по серверу Ubuntu. Wazuh зафиксировал множественные ошибки входа (Rule 5551 и 5763, уровень 10). Автоматизированная система SOAR (Shuffle + Python) перехватила алерт, авторизовалась в Wazuh API и отправила команду Active Response. IP атакующего был автоматически заблокирован в `iptables` на 60 секунд. На почту пришло уведомление.
