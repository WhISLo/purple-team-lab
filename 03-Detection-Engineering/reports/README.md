# Отчеты об инцидентах (Incident Response Reports)

В этой директории собраны отчеты об инцидентах (IR Reports), сформированные по результатам работы в лаборатории `purple-team-lab`. 

Каждый отчет описывает полный жизненный цикл инцидента: от момента срабатывания алерта (Detection) до этапа реагирования и анализа (Response & Analysis). Отчеты написаны в формате, приближенном к стандартам реальных SOC-команд (NIST SP 800-61).

## 📑 Структура отчетов

Каждый файл в этой папке следует единому шаблону, чтобы специалист по безопасности мог быстро найти нужную информацию:
1.  **Executive Summary (Резюме):** Краткое описание произошедшего (1-2 абзаца).
2.  **Timeline (Хронология):** Точное время ключевых событий (от первой атаки до блокировки).
3.  **Detection Details (Детали обнаружения):** Какие правила SIEM (Wazuh) сработали, какие Event ID были зафиксированы.
4.  **IOCs (Indicators of Compromise):** IP-адреса, хеши, имена процессов и другие артефакты.
5.  **MITRE ATT&CK:** Привязка действий атакующего к тактикам и техникам.
6.  **Evidence (Доказательства):** Ссылки на логи, скриншоты и вывод команд.

## 📂 Список инцидентов

### [001: Обход SRP и выполнение Shellcode в памяти (InstallUtil)](./001-installutil-srp-bypass.md)
*   **Тип:** Red Team / Defense Evasion.
*   **Суть:** Атакующий обошел политику SRP (Software Restriction Policies) и запустил C2-агент (Apollo) в памяти, не оставляя исполняемых файлов на диске.
*   **Результат:** Успешное выполнение полезной нагрузки через `InstallUtil.exe`. Wazuh зафиксировал активность, но стандартные правила не смогли детектировать инжект в память.

### [002: Автоматическая блокировка SSH-брутфорса (SOAR)](./002-soar-bruteforce-response.md)
*   **Тип:** Blue Team / Active Response.
*   **Суть:** Wazuh зафиксировал множественные неудачные попытки входа по SSH (Rules 5551 и 5763, уровень 10). Сработала кастомная SOAR-система (Wazuh ➔ Shuffle ➔ Python), которая автоматически авторизовалась в API и отправила команду на блокировку IP в `iptables`.
*   **Результат:** IP атакующего (10.10.10.203) был автоматически заблокирован на 60 секунд. Администратору отправлено Email-уведомление.
