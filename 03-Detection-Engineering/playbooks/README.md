## Плейбук: Реагирование на SSH-брутфорс (Автоматизированный)

**Триггер:** Алерт Wazuh уровня 10 (Rule 5551 или 5763).
**Действия (автоматические):**
1.  Wazuh фиксирует множественные ошибки входа и отправляет JSON-алерт в вебхук Shuffle.
2.  Shuffle проверяет уровень алерта (Condition > 7).
3.  Python-скрипт в Shuffle запрашивает JWT-токен у Wazuh API.
4.  Скрипт отправляет PUT-запрос на `/active-response` с командой `!firewall-drop`.
5.  Агент Wazuh на целевой машине выполняет `firewall-drop`, блокируя IP атакующего в `iptables` на 60 секунд.
6.  Shuffle отправляет Email-уведомление администратору с полями: IP атакующего, имя хоста, правило, полный лог.

**Действия (ручные, если автоматика не сработала):**
1.  Проверить логи в Wazuh Dashboard.
2.  Вручную заблокировать IP на файрволе.
3.  Проверить целевой хост на наличие компрометации.
