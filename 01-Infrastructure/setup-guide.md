# Руководство по развертыванию

## 1. Виртуальные машины
Скачаны образы: Kali Linux, Ubuntu Server 22.04, Windows Server 2016, Windows 10. В VirtualBox создана внутренняя сеть для связи между ВМ.

## 2. Настройка сети
Каждой ВМ назначен статический IP из подсети `10.10.10.0/24`. Проверка связности через `ping`.

## 3. Установка Wazuh (Ubuntu)
Установлен Docker. Клонирован репозиторий `wazuh-docker`, сгенерированы сертификаты, запущены контейнеры (Indexer, Manager, Dashboard). Доступ: `https://10.10.10.20`.

## 4. Установка Mythic C2 (Ubuntu)
Клонирован репозиторий `Mythic`, собран `mythic-cli` (`sudo make`). Запуск: `sudo ./mythic-cli start`. Установлены HTTP-профиль и агент Apollo. Доступ: `https://10.10.10.20:7443`.

## 5. Установка агентов Wazuh (Windows)
Скачан MSI-пакет агента, установлен с указанием manager IP `10.10.10.20`.
