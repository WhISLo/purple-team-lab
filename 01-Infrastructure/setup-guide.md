# Гайд по настройке

Пошаговая инструкция по развертыванию , настройке сети и установке Wazuh/Mythic.


Скачал образы ОС и поднял на ещё пустых виртуальных машинах.
Для доступа к сети оставил по умолчанию nat, но для связи между собой подключил доп виртуальный адаптер
В моменте, когда пробовал настроить автоматическое логирование, закончилась память на машине с Ubuntu пришлось расширять диск,
с 25 гб до 80 гб, и объеденять диски для единого хранилища, сначала не находило созданый доп диск, оказалось для этого
надо запустить VBox от админа, только тогда он создастя и будет отображаться. Потом возникла проблема с объединением, 
она возникала в связи с тем что логирование продолжалось и во время работы по записи файлов на диск прерывался процесс объединения.
Так же пришлось остановить рабочие Docker контейнеры и после всё успешно объединилось, возобнавил работу контейнеров.
